# Maze Bots — Cartoon-Pixel AI & PvP Arena

> **Play live in your browser (zero install):** **[https://jiean2306.github.io/robot-maze-battle/](https://jiean2306.github.io/robot-maze-battle/)**

A fast-paced, comic-outlined **cartoon-pixel tank arena** built in vanilla HTML5 Canvas, CSS, and Web Workers. Battle friends locally (1P / 2P), pit built-in tactical AI personalities against each other, **customize every robot's look in the Skin Workshop**, track **every combat stat across multi-match tournaments**, or drop in **self-learning JavaScript AIs** generated by LLMs like Gemini, Claude, ChatGPT, Grok, and DeepSeek.

---

## Highlights

- **Cartoon + Pixel-Nostalgic Aesthetics:** Warm pastel grid UI paired with bold ink outlines, pixel-brick maze walls, candy-colored special tiles, chunky offset shadows, comic elimination callouts (`POW!`, `BOOM!`, `ZAP!`), and expressive speech bubbles.
- **Robot Skin Workshop:** Customize every slot's **Primary & Accent Colors**, **6 Body Shapes**, **5 Wheel/Mobility Styles** (*Treads*, *Monster Tires*, *Hover Jets*, *Spike Rollers*, *Twin Sleds*), **4 Cannon Styles**, **8 Faces/Emblems** (*Pixel Eyes*, *Cyber Visor*, *Hero Star*, plus AI brand emblems), **8 Accessories** (*Gold Crown*, *Ninja Bandana*, *Radar Antenna*, *Cat Ears*, *Viking Horns*, *Spin Beanie*, *Pixel Halo*), and **5 Movement Trails** — complete with an animated **Test Fire!** preview canvas.
- **Multi-Match Series & Full-Stats Leaderboard:** Set your tournament series length (`1–50` matches), play manually or fast-forward via **Auto-Run Series (`4×`)**, and inspect full sortable standings (`Pts`, `Wins %`, `Kills`, `Deaths`, `K/D`, `Dmg Dealt`, `Dmg Taken`, `Accuracy`, `Banks`, `Pillar Boosts`, `Drops`, `Regen +HP`, `Close Dodges`, `Avg Survival`) plus a per-match history log.
- **AI Code Arena & Self-Learning Brains:** Click **Copy AI Prompt** to get the complete arena API spec for any LLM, paste the returned JavaScript into a **Code** slot, and watch it execute inside an isolated **Web Worker sandbox**. Bots can persist strategy weights in `localStorage` via `onMatchEnd(report, brain)` and visibly evolve across generations (`Gen #1`, `Gen #2`, ...).
- **Dynamic Tactical Combat:**
  - **100% Randomized Spawns** each match with anti-LOS spawn protection.
  - **Ricochet Bank Shots** (up to 3 wall bounces with configurable arena rules) and **4 Center Bumper Pillars** that supercharge bullets (`+15%` DMG).
  - **Special Candy Wall Tiles** triggered when bullets bounce off them: **Orange Range+**, **Blue Speed+**, and **Green 3× Spread**.
  - **Tactical Regen:** Spend `3` ammo at once to heal `+10%` of current HP (`10s` cooldown).
  - **8 Power-Up Drops:** *Piercing*, *Wall-Breach Penetrate*, *Ultra-Ricochet*, *Laser Beam*, *Speed Boost*, *Shield*, *Mirror Reflect*, and *Spike Trap*.
  - **Synthesized Retro Chiptune BGM & SFX** via the Web Audio API (toggleable in the top bar).

## Controls

| Action | Player 1 (`P1`) | Player 2 (`P2`) |
| :--- | :--- | :--- |
| **Drive Forward / Reverse** | `W` / `S` | `Arrow Up` / `Arrow Down` |
| **Rotate Chassis & Cannon** | `A` / `D` | `Arrow Left` / `Arrow Right` |
| **Fire Forward** | `Space`, `F`, or `Left Click` *(1P)* | `Enter`, `/`, or `Right Shift` |
| **Tactical Regen (`-3` Ammo, `+10% HP`)** | `E` or `Q` | `.` (Period) or `Numpad 0` |
| **Toggle Pause / LiDAR Rays** | `P` / `L` | `P` / `L` |

> Tip: Player 1 & Player 2 tanks also charge an automatic **Aimbot Lock** every 2nd shot when an enemy is lined up!

## Run Locally

No build tools, bundlers, or external dependencies are required — everything runs purely client-side:

```bash
# Clone the repository
git clone https://github.com/jiean2306/robot-maze-battle.git
cd robot-maze-battle

# Serve locally with any static server (pick one):
npx serve .
# OR
python -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080) (or `index.html` directly for offline testing; note a local HTTP server is recommended so Web Workers load cleanly across all browsers).

## Writing & Sharing Custom AI Bots

1. Open the game and switch any robot card to **Code** mode.
2. Click **Copy AI Prompt** (or **View Spec**) in Setup to copy the complete physics, LiDAR, tile grid, special wall, power-up, and self-learning `brain` API prompt.
3. Paste the prompt into your favorite AI coding assistant (or write your own `META` + `think(state)` + `onMatchEnd(report, brain)` script).
4. Paste the resulting JavaScript into the **Code** modal, click **Validate & Save Bot Code**, and compete!
5. Save or share `.js` bot files directly with the **Download .js** / **Upload .js** buttons inside the Code Editor.
